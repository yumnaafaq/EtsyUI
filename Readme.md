# 🛍️ Etsy Homepage Clone

A responsive **Etsy-inspired homepage clone** built using **HTML** and **CSS**. This project focuses on recreating the layout and design of a modern e-commerce landing page while practicing core frontend development concepts.

> **Note:** This is an educational project created for learning purposes. It is inspired by Etsy's homepage but is not affiliated with or endorsed by Etsy. All the images used are from unsplash, and belong to their rightful owners.


---

## ✨ Features

- Responsive navigation bar
- Search bar with icons
- Category navigation menu
- Hero banner section
- Featured interest cards
- Product showcase section
- Multi-column footer
- Hover animations
- Responsive design for desktop, tablet, and mobile
- Built without JavaScript

---

## 🛠️ Technologies Used

- HTML
- CSS
- Flexbox
- Font Awesome

---

## 🎯 Learning Objectives

This project helped me practice:

- Semantic HTML
- Flexbox layouts
- Responsive web design
- CSS positioning
- Hover effects and transitions
- Building reusable UI components
